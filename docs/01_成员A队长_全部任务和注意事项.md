# 成员A队长全部任务和注意事项

基于中国气象局台风最佳路径数据集的 CNN 与 Cesium 项目

成员A兼任队长，负责把数据、算法、可视化和提交材料组织成可复现、可演示、可验收的完整项目。

## 一 工作边界

**项目统一定位：**本项目基于中国气象局台风最佳路径数据集，利用台风历史轨迹、强度等级、近中心最大风速及移动趋势特征，构建轻量化深度学习预测模型，并结合 Cesium 实现台风路径、强度变化和影响范围的三维动态可视化。

**工作量原则：**约50%：项目总负责、数据与模型主责、系统联调和最终技术审核。

## 二 使用平台

| 工作内容 | 推荐平台与工具 | 使用要求 |
|---|---|---|
| 数据处理与建模 | Python 3.10+，PyTorch，pandas，NumPy | 以项目已有代码环境为准，固定依赖版本 |
| 实验开发 | JupyterLab 或 VS Code | 二选一作为主开发环境，保留运行命令 |
| 版本管理与协作 | Git 与 Gitee 或 GitHub 私有仓库 | 代码、结果和文档按版本提交 |
| 结果交付 | CSV，JSON，PNG | 统一字段、单位和命名规则 |

## 三 项目统筹与口径管理

成员A兼任队长，承担约50%的工作量，负责把数据、模型、系统和提交材料组织成一个可验证的闭环。

- 锁定数据源、字段、数据年份、采样间隔、输入历史时间窗和预测时效。
- 明确主模型为1D-CNN，多步预测目标为未来6、12、24小时；若实际实现不同，立即同步全组并统一文档。
- 建立项目总表，记录数据版本、代码版本、实验编号、指标单位、系统版本和材料版本。
- 每个阶段结束时组织验收，阻止未经验证的说法进入最终材料。

## 四 数据处理与特征工程

不更换现有中国气象局台风最佳路径数据集，在原有变量上补充轻量、可追溯的代理特征。

- 保留经度、纬度、近中心最大风速、风力等级、经纬度变化量等现有特征。
- 组织生成月份、季节、所在海域、过去24小时移动方向、过去24小时强度变化率等代理特征。
- 完成缺测处理、时间排序、台风编号分组、滑动窗口构造和训练验证测试划分，并输出样本统计表。
- 避免随机打乱造成时间泄漏；测试集划分规则必须能在方案中解释。

## 五 模型与实验组织

先保证基础模型和核心指标可靠，再根据剩余时间扩展对比、消融和不确定性表达。

- 跑通1D-CNN基础模型，输出位置和强度预测结果。
- 实现持续性预测，并组织MLP、LSTM或GRU中的可行基线，至少保留一到两个可复现实验。
- 安排消融实验：去掉经纬度差分、去掉强度特征、去掉季节特征，并记录误差变化。
- 用多次dropout或历史误差统计生成预测范围；只有完成计算和验证后才能称为预测区间或预测走廊。
- 审核位置误差的单位，优先使用度或换算为公里；风速单位统一使用实际字段单位，禁止写错为km/s。

## 六 系统联调与最终验收

队长负责模型输出和Cesium展示之间的接口契约，确保系统中的历史、预测和范围表达一致。

- 制定预测JSON字段：台风编号、时间、经纬度、风速、风力等级、预测时效、数据类型和区间字段。
- 与成员B联调历史轨迹、预测轨迹、强度变化、风圈、影响范围和预测走廊。
- 检查演示案例的输入时间、预测起点、预测终点、时间轴和图表是否一致。
- 完成最终技术审核：代码能运行、模型能加载、指标可复现、系统能演示、材料不越界。

## 交付物和完成标准

| 交付物 | 必须包含 | 完成标准 |
|---|---|---|
| 数据与特征说明 | 字段表、数据划分、特征处理和样本统计 | 成员A确认，成员B或C交叉检查 |
| 模型与实验包 | 1D-CNN、基线、消融、不确定性结果和指标表 | 至少一键复现主结果 |
| 预测接口规范 | 统一JSON示例、单位、时间格式和字段说明 | 成员B可直接接入 |
| 最终技术版本 | 代码、模型、运行说明、系统和结果表 | 第22天可交付，第25天冻结 |

## 注意事项

- 不得写融合多源气象格点数据、卫星云图或ERA5再分析数据，除非真实接入并参与训练。
- 不得把离线历史回放写成实时气象服务；没有真实概率模型时，不得把视觉范围写成概率锥体。
- 统一1949-2023或实际核验后的年份范围，不得在Word和PPT中出现不同版本。
- 所有指标先留空或写待测，不能为了材料完整而编造数值。
- 出现延期时，优先取消完整GAN、多生成器和复杂气象场，保留1D-CNN加Cesium核心闭环。

## 交接要求

- 所有代码、数据处理脚本、实验记录和素材使用统一命名，并在提交前写明版本日期。
- 涉及指标、单位、样本量和预测时效的内容必须以队长确认的结果表为准。
- 任何未实现功能不得在作品方案、答辩PPT、视频字幕或系统界面中表述为已完成。
