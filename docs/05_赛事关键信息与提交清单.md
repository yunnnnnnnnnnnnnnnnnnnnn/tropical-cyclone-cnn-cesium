| 节点 | 时间 | 说明 |
|---|---|---|

## 二、参赛方向

开放式命题三个方向，本项目属于 **（一）人工智能赋能气象**（面向预报/预测）。

## 三、必须提交的材料（10-15 前）

| 材料 | 硬性规范 |
|---|---|
| 作品名称 | ≤ 20 字 |
| 作品简介 | ≤ 300 字，按「问题-方案-效果-应用」逻辑 |
| 作品方案 | PDF ≤ 10M |
| 演示视频 | MP4，3–5 分钟，≤ 300MB |
| 答辩 PPT | 转 PDF |
| 佐证材料 | 合并为 1 个 PDF |
| 其他材料（代码包等） | 百度网盘分享链接（永久有效、自动提取码） |

## 四、评分规则（100 分，决定投入重点）

| 评分项 | 分值 |
|---|---|
| 创新性 | 25 |
| AI 技术应用 | 20 |
| 需求分析 | 15 |
| 项目实施 | 15 |
| 应用成效 | 15 |
| 总结与展望 | 10 |

> **创新性（25）+ AI 技术应用（20）合计 45 分**，是拉开差距的核心——模型与可视化要做出「可复现、有对比」的效果，而非只求跑通。

## 五、硬性合规要求（一票否决项）

- **匿名化**：作品方案、演示视频、答辩 PPT 中均不得出现学校名称与指导教师信息。
- **创新层级标注**：数据级 / 特征级 / 模型级 / 系统级 / 应用级（本项目倾向「模型级 + 系统级」）。
- **原创性**：不得抄袭、雷同、伪造，引用需标注并授权。
- **「删减必替代」原则**：某部分不适用须说明理由并提供等效替代论证。
- **完整闭环**：问题定义 → 数据选用 → 方法设计 → 实现过程 → 效果验证 → 价值总结。
