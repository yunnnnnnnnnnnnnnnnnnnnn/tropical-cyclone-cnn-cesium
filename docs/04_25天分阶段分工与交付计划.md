# 25天分阶段分工与交付计划

基于中国气象局台风最佳路径数据集的 CNN 与 Cesium 项目

本计划按成员A兼任队长约50%、成员B约25%、成员C约25%的工作量安排任务。第3、7、12、16、19、22、25天设置硬验收点，任何阶段未通过时先收缩范围，再保证核心链路可交付。

## 一 项目核心链路

数据处理 → 1D-CNN及对比实验 → 指标验证 → 预测JSON → Cesium三维展示 → 方案、PPT、视频和提交包。

## 二 阶段任务与交付

| 阶段 | 成员A队长 | 成员B | 成员C | 验收点 |
|---|---|---|---|---|
| 1-3天 统一口径 | 锁定数据版本、字段、时效、指标和命名；建立项目总表。交付：项目口径表 | 确认系统目录和离线启动方式。交付：页面与接口清单 | 建立方案、PPT、视频和提交包目录。交付：材料框架 | 第3天：三人确认同一数据、时效、单位和表述。 |
| 4-7天 基线跑通 | 跑通1D-CNN、持续性预测和一个可行基线，确定主指标和输出格式。交付：基线代码、初始结果 | 用模拟JSON搭出历史轨迹、预测轨迹和时间轴。交付：可操作原型 | 完成背景、需求、总体设计初稿。交付：方案初稿 | 第7天：主模型能运行，系统能展示，材料有可引用结构。 |
| 8-12天 轻量改进 | 完成代理特征、数据泄漏复核与未来6、12、24小时多步预测。交付：改进模型、特征脚本和对比结果 | 接入真实预测JSON，完成强度和影响范围基础展示。交付：接口接入版 | 补写技术方案、创新点和实验设计。交付：方案第二稿 | 第12天：模型、接口和文稿字段及时效一致。 |
| 13-16天 实验联调 | 完成消融实验、不确定性统计和最终结果表；定下最终模型。交付：结果表、误差图和JSON规范 | 完成地图、图表、图例、范围和时间轴联调。交付：系统联调版 | 将最终结果写入方案和PPT，删除未实现表述。交付：材料第三稿 | 第16天：模型、结果、JSON和Cesium系统闭环联通。 |
| 17-19天 案例与演示 | 审核稳定移动、转向或强度变化案例，冻结演示数据。交付：案例选择和技术审查 | 完成端到端演示流程和截图。交付：演示版系统 | 录制3-5分钟视频初版并制作PPT演示页。交付：视频初版、PPT初版 | 第19天：从启动到总结全流程不报错，画面与数据一致。 |
| 20-22天 形成可交版本 | 完成技术版本、运行说明和最终验收清单。交付：代码模型运行包 | 优化加载、异常处理和离线运行体验。交付：系统候选版 | 完成方案、PPT、视频和提交目录候选版。交付：全套材料候选版 | 第22天：所有提交材料均有可交版本，进入冻结准备。 |
| 23-25天 冻结提交 | 冻结模型、系统和指标；完成最终技术检查。交付：最终确认单 | 检查不同电脑或浏览器下的离线演示。交付：运行确认 | 完成匿名化、格式、大小、时长和目录检查并上传。交付：最终提交包 | 第25天：文件齐全、格式合规、可打开、可运行、可解释。 |

## 三 关键交付清单

| 时间点 | 必须具备 | 未完成时的处理 |
|---|---|---|
| 第3天 | 统一数据源、字段、时效、单位和项目表述 | 暂停扩展功能，先完成口径确认 |
| 第7天 | 1D-CNN基线、模拟系统、材料框架 | 取消非必要基线，保留主模型 |
| 第12天 | 代理特征、多步预测和JSON接入 | 减少代理特征，保留最可解释的一组 |
| 第16天 | 消融结果、最终模型和系统联调 | 取消高级范围表达，先保证轨迹和强度展示 |
| 第19天 | 稳定案例和完整演示流程 | 只保留一个最稳定案例 |
| 第22天 | 全套可交材料候选版 | 停止新增功能，集中修复格式和事实 |
| 第25天 | 冻结版本和最终提交包 | 只做必要的格式修复和提交检查 |

## 四 风险降级顺序

第一优先级：取消完整GAN、多生成器、复杂气象场和实时接入，保留1D-CNN加Cesium核心闭环。

第二优先级：减少代理特征，只保留能稳定计算并能解释的月份、季节和移动趋势特征。

第三优先级：取消高级不确定性表达，改为经过误差统计的简单预测范围或仅展示确定性预测。

任何降级都要同步修改作品方案、PPT、视频字幕、系统图例和运行说明，避免前后不一致。

## 五 统一注意事项

- 不写融合多源气象格点数据、卫星云图或ERA5再分析数据，除非实际接入并训练。
- 不把离线历史回放写成实时系统，不把没有计算依据的范围写成概率锥体。
- 指标、单位、年份、样本量和预测时效必须以队长确认的结果表为准。
- 所有功能和结果必须能通过代码、数据、截图或演示步骤说明其来源。
