# 成员C全部任务和注意事项

基于中国气象局台风最佳路径数据集的 CNN 与 Cesium 项目

成员C负责把已完成且已验证的项目内容整理为符合赛事要求的最终交付材料。

## 一 工作边界

**项目统一定位：**本项目基于中国气象局台风最佳路径数据集，利用台风历史轨迹、强度等级、近中心最大风速及移动趋势特征，构建轻量化深度学习预测模型，并结合 Cesium 实现台风路径、强度变化和影响范围的三维动态可视化。

**工作量原则：**约25%：作品方案、答辩PPT、演示视频、提交包和合规检查主责。

## 二 使用平台

| 工作内容 | 推荐平台与工具 | 使用要求 |
|---|---|---|
| 文字与答辩材料 | Microsoft Word，Microsoft PowerPoint | 使用成员A确认的结果表和截图 |
| 视频制作 | 剪映 或 CapCut，OBS Studio 可选 | 输出MP4，保留工程文件和素材目录 |
| 图表与文件整理 | Excel 或 WPS 表格，PDF导出工具 | 统一图表编号、单位和文件命名 |
| 协作与提交 | 共享云盘或 Git 附件发布页 | 仅上传最终确认版本，清理临时文件 |

## 三 作品方案

成员C承担约25%的工作量，负责把已验证的技术内容转化为规范、清晰、可提交的材料。

- 按赛事要求组织作品名称、作品简介、背景与需求、总体设计、技术方案、创新点、应用价值和成果展示。
- 以成员A确认的项目表述为准：只使用中国气象局台风最佳路径数据集和已实现的特征、模型、系统。
- 将参考项目的可借鉴思路写成实际完成的特征工程、基线、消融或不确定性结果，未完成内容放入后续计划。
- 统一数据年份、样本量、预测时效、指标名称、单位和图表编号。

## 四 答辩PPT与演示视频

材料重点是让评审快速看懂问题、方法、证据和系统效果。

- 制作技术路线、数据流程、1D-CNN结构、实验对比、消融结果、Cesium界面和应用价值页面。
- 将演示流程控制在3到5分钟：项目定位、选择台风、历史回放、预测轨迹、强度变化、范围表达和结果总结。
- 视频使用最终系统和最终指标，字幕、旁白和页面文字保持一致。
- 为系统截图和实验图补充简短图注，确保读者能识别历史、预测、输入、输出和单位。

## 五 提交包与合规检查

成员C负责材料完整性，但技术内容必须由成员A最终审核。

- 整理作品方案PDF、答辩PPT、演示视频、代码包、模型文件、数据说明和运行说明。
- 建立提交目录和文件清单，检查压缩包内没有临时文件、个人路径、账号、密钥或无关大文件。
- 按规则检查作品名称不超过20字、简介不超过300字、PDF不超过10M、视频为MP4且3到5分钟和300MB以内。
- 检查匿名化要求：按赛事规则清理学校、学院、指导教师和队员身份信息；若规则另有指定格式，以规则原文为准。

## 交付物和完成标准

| 交付物 | 必须包含 | 完成标准 |
|---|---|---|
| 作品方案 | 正文、图表、引用、创新点、应用价值和成果展示 | 第22天形成可交版本 |
| 答辩PPT | 技术路线、结果、系统截图和演示逻辑 | 与最终系统和指标一致 |
| 演示视频 | 3到5分钟MP4，展示真实可运行功能 | 画面、字幕、旁白无冲突 |
| 提交包 | 方案、PPT、视频、代码、模型、数据说明和运行说明 | 第25天完成清单验收 |

## 注意事项

- 不得自行修改模型指标、样本数量、年份、单位或实验结论。
- 不得将参考项目中的ERA5、卫星云图、多源格点数据或复杂模型写成当前项目已经使用。
- 不得把离线回放写成实时业务系统，不得把视觉范围写成未经计算的概率预测。
- 所有截图必须删除无关模板内容，所有图表必须有标题、单位、图例和来源说明。
- 材料定稿后只允许修正格式、错别字和已确认事实；技术变更必须回到成员A审批。

## 交接要求

- 所有代码、数据处理脚本、实验记录和素材使用统一命名，并在提交前写明版本日期。
- 涉及指标、单位、样本量和预测时效的内容必须以队长确认的结果表为准。
- 任何未实现功能不得在作品方案、答辩PPT、视频字幕或系统界面中表述为已完成。
