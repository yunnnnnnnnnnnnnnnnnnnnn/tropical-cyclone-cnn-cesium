# 基于 CNN 与 Cesium 的热带气旋可视化与预测

> 基于中国气象局台风最佳路径数据集的热带气旋路径与强度预测，结合 Cesium 三维可视化。

## 项目简介

本项目利用台风历史轨迹、强度等级、近中心最大风速及移动趋势特征，构建**轻量化深度学习预测模型（1D-CNN）**，预测台风未来 **6 / 12 / 24 小时**的位置与强度变化，并结合 **Cesium** 实现台风路径、强度变化和影响范围的三维动态可视化。

## 口径约束（重要）

- 主模型为 **1D-CNN**，多步预测目标为未来 **6 / 12 / 24 小时**；若实现变更，需同步更新全组文档。
- 只使用**中国气象局台风最佳路径数据集**；不写融合多源格点、卫星云图或 ERA5 再分析数据（除非真实接入并训练）。
- 指标、单位、年份、样本量、预测时效**以队长确认的结果表为准**；所有指标先留空或写「待测」，不得编造数值。
- 不把离线历史回放写成实时系统；没有真实概率模型时，不把视觉范围写成「概率锥体」。
- 任何未实现功能，不得在方案、PPT、视频字幕或系统界面中表述为已完成。
