# model/ — 模型模块（成员 A）

数据处理与 1D-CNN 预测模型。

## 职责

- 数据：台风最佳路径数据集（`data/`，不入库）
- 特征工程：经度/纬度/风速/风力等级/经纬度变化 + 代理特征（月份、季节、海域、移动方向、强度变化率）
- 模型：1D-CNN 主模型 + 持续性预测 / LSTM 基线 + 消融 + 不确定性
- 输出：预测 JSON（台风编号、时间、经纬度、风速、风力等级、预测时效、数据类型、区间）

## 目录

```
model/
├── src/       # 代码
│   ├── data_loader.py    # 数据读取与滑动窗口
│   ├── features.py       # 特征工程
│   ├── model.py          # 1D-CNN 定义
│   ├── train.py          # 训练
│   └── predict.py        # 推理并导出预测 JSON
└── data/      # 数据集（.gitignore 忽略）
```
